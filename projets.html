Mes Projets Réalisés

Projet AP1 : Solution Informatique Nomade Sécurisée

Résumé : Ce projet visait à concevoir un poste de travail mobile hautement sécurisé (Hardening). L'objectif était de réduire la surface d'attaque du système Windows et de créer un "Master" prêt à être déployé massivement.

Technologies & méthodes utilisées :

  • Sécurisation Système : Désactivation de NTLMv1, SMBv1, PowerShell V2 et de l'Auto-run.
  • Protection : Configuration de Microsoft SmartScreen et Exploit Protection.
  • Gestion logicielle : Utilisation de Chocolatey pour l'automatisation des installations.
  • Déploiement : Création d'une image système et clonage avec Clonezilla.

Projet AP2 : Infrastructure Réseau & Services PARCUS

Résumé : Réalisation complète d'une infrastructure virtualisée pour une entreprise. Ce projet intègre la segmentation réseau, la gestion centralisée des utilisateurs et la mise en place d'un centre de services IT.

Technologies & méthodes utilisées :

  • Virtualisation : Déploiement sous hyperviseur Proxmox VE.
  • Réseau : Configuration de pfSense (Pare-feu, gestion WAN/LAN, DHCP).
  • Services de Domaine : Installation de Windows Server 2022 avec Active Directory (AD DS).
  • Gestion de Parc : Mise en place de GLPI sur serveur Debian pour l'inventaire et le helpdesk.

Projet AP3 : SI Hautement Disponible et Interconnecté (ECP)

Résumé : Mise en place d'une infrastructure hautement disponible pour un centre de formation (ECP). Le projet consistait à assurer la continuité des services (AD, Fichiers, DHCP) sur deux sites distants interconnectés via un tunnel VPN.

Technologies & méthodes utilisées :

  • Haute Disponibilité : Configuration de DFS / DFSR pour la réplication de fichiers et du Failover DHCP.
  • Interconnexion : Mise en place d'un tunnel VPN Site-à-Site sécurisé entre les infrastructures.
  • Infrastructure Microsoft : Déploiement de contrôleurs de domaine redondants et gestion avancée des GPO.
  • Sécurité : Filtrage inter-sites via pfSense et authentification centralisée des utilisateurs.
  • Sauvegarde : Solution de stockage NAS/SAN via iSCSI pour la protection des données critiques.

Projet AP4 : Résilience et Connectivité - Sécurité Civile (COD)

Résumé : Modernisation du SI du Centre Opérationnel Départemental pour la Sécurité Civile. L'objectif était de garantir la résilience des communications critiques (VoIP, Messagerie) et de permettre un accès sécurisé aux agents sur le terrain.

Technologies & méthodes utilisées :

  • Haute Disponibilité : Mise en œuvre du protocole CARP sur pfSense pour la redondance des pare-feux.
  • Communications : Déploiement de Microsoft Exchange et de la téléphonie sur IP avec XIVO.
  • Mobilité : Configuration d'un accès distant via OpenVPN Road Warrior.
  • Applications métiers : Installation du logiciel eBrigade et supervision des services.
  • Réseau : Gestion de la résilience Internet via du multi-WAN sur hyperviseur Proxmox.
